# 歷年各年齡層教育程度（BI 網頁）

用內政部「十五歲以上人口按年齡及教育程度」統計，做成可互動篩選的 BI 網頁。

網頁：尚未發佈（預定 https://rowan0629.github.io/HW1006/，需先啟用 GitHub Pages）

資料來源：內政部（戶政司），《十五歲以上人口按年齡及教育程度(96)》；補充資料為新北市政府資料開放平臺「十五歲以上現住人口之教育程度─按年齡別」
資料期間：全國、縣市別，民國 96 年底至 114 年底（西元 2007–2025 年，每年一筆）；新北市補充資料為西元 1998–2024 年
主題：各年齡層大專以上比率的長期變化，以及性別差異（暫定，待確認）

## 資料欄位

### 原始檔（`.xls`）

- 工作表名稱是民國年：`96.1(年齡)` 是年齡表，`96.2(縣市)` 是縣市表；單位：人
- 年齡表每個年齡層佔三列（計、男、女），年齡標籤只寫在中間那列（合併儲存格）；共 11 個年齡層，最後一組是「65 歲以上」，另有總計列
- 教育程度分研究所（博士、碩士）、大學、專科（二、三年制，五年制後二年、前三年）、高中、高職、國（初）中、初職、國小、自修、不識字；多數項目分畢業、肄業
- 零值寫成「—」，數字含千分位逗號，表頭為多層合併

### 預計輸出（規劃，尚未產生）

| 欄位 | 說明 |
|---|---|
| year | 民國年 |
| age_group | 年齡層 |
| sex | 計／男／女 |
| education | 教育程度 |
| completion | 畢業／肄業 |
| count | 人數 |

## ETL 處理與驗證

**預計處理**（尚未實作）

- 把多層合併表頭攤平成單一欄名，把年齡標籤往下補齊到三列
- 「—」視為 0，去除千分位逗號，去掉說明列與空白列
- 96–97 年研究所沒有分博士、碩士，與 98 年之後的分類對齊
- 105 年起表頭由「高中」「高職」改為「普通教育（高中）」「職業教育（高職）」，統一欄名
- 縣市表 96–98 年含「臺灣地區」「臺灣省」小計列，「福建省」是金門與連江小計，不可直接加總

**預計驗證**（尚未實作）

- 每個年份的 11 個年齡層加總等於總計
- 每個年齡層、每個欄位：男 + 女 = 計
- 識字合計 + 不識字 = 總計
- 大專以上比率與內政部戶政司報告表 3-2-5-1 對照（97、103、107 年）

**已在分析階段手動確認的結果**（程式與紀錄尚未放入 repo）

- 19 個年份的年齡表，上述前三項核對全部通過
- 大專以上比率：97 年 34.91%、103 年 41.75%、107 年 45.52%，與戶政司報告完全一致

## 指標定義

| 指標 | 定義 |
|---|---|
| 大專以上比率 | （研究所 + 大學 + 專科〔二、三年制與五年制後二年〕人數，含畢業與肄業）÷ 該組十五歲以上人口 × 100；不含五專前三年 |
| 性別差距 | 女性大專以上比率 − 男性大專以上比率（百分點） |
| 年齡層 | 5 歲一組：15～19、20～24 … 60～64，最後一組為 65 歲以上 |

## 限制

- 資料是戶籍登記人口的教育程度註記，不是抽樣調查
- 「大專以上」在這裡包含肄業，不含五專前三年；與其他定義的數字不能直接比較
- 96–97 年研究所未分博士、碩士，博士與碩士的圖只能從 98 年開始
- 教育程度標準分類於民國 105 年 1 月第 5 次修正，欄位用語與分類在 105 年前後不同
- 年齡層是 5 歲一組，最後一組為 65 歲以上
- 新北市補充資料年份為西元，與內政部檔案的民國年不同
- 圖表只描述高低與差異，不代表因果
