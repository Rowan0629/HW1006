# 高雄歷年碩博士人數趨勢

用內政部「十五歲以上人口按年齡及教育程度」統計，做成可互動篩選的 BI 網頁，觀察高雄碩士、博士學歷人口的長期變化。  
網頁：https://rowan0629.github.io/HW1006/  
主題：高雄十五歲以上人口中碩士、博士學歷人數與占比的長期趨勢，並與全國比較
資料來源：內政部（戶政司），《十五歲以上人口按年齡及教育程度(96)》縣市表
資料期間：民國 96 年底至 114 年底（西元 2007–2025 年，每年一筆）



## 目錄

```
Data/                          所有原始資料與參考文件（皆未經修改）十五歲以上人口按年齡及教育程度(96).xls 原始檔（內政部）
etl/etl.py                    ETL：依表頭文字找欄位、合併高雄縣市、計算研究所／博士／碩士、輸出 CSV，並執行驗證
etl/validate.py               驗證程式（6 項檢查，全部通過 exit 0）
etl/validation_log.txt        ETL 每次執行的驗證紀錄
etl/build_data.py             把 output/ 轉成網頁載入的 docs/data.js，並核對關鍵數字
output/kaohsiung_gradschool.csv   ETL 後的標準資料（UTF-8 with BOM）
docs/index.html               BI 網頁（單一檔案，GitHub Pages 從 docs/ 發佈）
docs/data.js                  網頁用資料（window.GRAD_DATA，含 meta 註記）
```

## 重新產生資料

需要 [uv](https://docs.astral.sh/uv/)；套件（`xlrd`，讀舊版 `.xls`）由腳本內的 inline metadata 自動安裝。

```
uv run etl/etl.py          # 產生 output/kaohsiung_gradschool.csv，並把驗證結果寫入 etl/validation_log.txt
uv run etl/validate.py     # 單獨重跑驗證
uv run etl/build_data.py   # 產生 docs/data.js 並核對
```

在本機看網頁：直接雙擊 `docs/index.html`（圖表用 ECharts CDN，需要網路）。

## 資料欄位

### 原始檔（`.xls`，本主題使用「縣市」表）

- 工作表名稱是民國年：`96.2(縣市)` 是 96 年的縣市表；單位：人
- 列是縣市（另有全國「總計」列），欄是教育程度：總計、識字合計、博士（畢業、肄業）、碩士（畢業、肄業）、大學、專科、高中、高職、國（初）中、初職、國小、自修、不識字
- 96–97 年只有「研究所」（畢業、肄業），沒有分博士與碩士
- 縣市表沒有年齡與性別
- 零值寫成「—」，數字含千分位逗號，表頭為多層合併

### 輸出（`output/kaohsiung_gradschool.csv`）

| 欄位 | 說明 |
|---|---|
| year | 民國年 |
| area | 高雄／全國（兩者各自一列，不相加） |
| education | 研究所／碩士／博士（96–99 年只有研究所；100 年起三者都有） |
| completion | 畢業／肄業 |
| count | 人數 |
| population_15 | 該區十五歲以上人口 |

## ETL 處理與驗證

**處理**（`etl/etl.py`）

- 依表頭文字（不是硬編碼欄號）找欄位，並確認位置符合預期；「不識字率」是比率欄，不參與加總
- 把多層合併表頭攤平成單一欄名，「—」視為 0，去除千分位逗號，去掉說明列與空白列
- **高雄**：96–98 年表有「高雄縣」與「高雄市」兩列，兩列相加；99 年起只有合併後的「高雄市」
- 96–99 年只使用「研究所」合計（博士 + 碩士）；100 年起才拆成博士與碩士
- **全國**：取縣市表的「總計」列，不加總各縣市（避免 96–98 年的「臺灣地區」「臺灣省」小計列、「福建省」小計造成重複計算）

**驗證**（`etl/validate.py`，結果見 `etl/validation_log.txt`）

- 每個年份：博士 + 碩士 = 研究所合計（98 年起）
- 高雄 96–98 年兩列相加後，與 99 年之後的合併範圍趨勢連續（98 到 99 年十五歲以上人口變動與其他年度相近）
- 全國十五歲以上人口，縣市表的總計與年齡表的總計相等
- 各縣市列加總（排除小計列）等於全國總計

**驗證結果**（19 年逐年，目前全部通過）

- 各年份縣市列加總（排除臺灣地區、臺灣省、福建省小計列）等於全國總計；96–98 年若直接加總所有非總計列，會多算約 3,400 萬人
- 縣市表總計與年齡表總計逐年相等（114 年為 20,617,242 人）
- 100 年起博士 + 碩士 = 研究所；高雄 98→99 年十五歲以上人口變動 +0.89%，與前後年度相近
- 高雄研究所合計 96 年 83,746 人、114 年 214,075 人（含畢業與肄業，兩列相加後）
- 博士占研究所的比率：全國 98 年 3.3%、99 年 5.0%、100 年 9.2%，之後在 9.2–9.6% 之間

## 指標定義

| 指標 | 定義 |
|---|---|
| 碩士（博士）人數 | 十五歲以上人口中，學歷為碩士（博士）者的人數。預設計算「畢業」（取得學位），可切換為「含肄業」 |
| 碩博士占比 | 碩士與博士人數 ÷ 該區十五歲以上人口 × 100，分子隨「畢業／含肄業」切換 |
| 研究所合計 | 博士 + 碩士。96–99 年只有此項 |
| 高雄範圍 | 96–98 年為高雄縣 + 高雄市；99 年起為合併後的高雄市 |

## 網頁互動

- 切換：碩士／博士／研究所合計，畢業／含肄業，人數／占比
- 比較對象：高雄與全國（各畫一個數列，不相加）
- 年份區間可拖拉；四張圖：人數、占十五歲以上人口比例、博士占研究所比例、高雄與全國的差距（百分點）
- 圖：折線圖／長條圖可切換，並標示 99 年的高雄縣市合併與 100 年的博碩分列起點

## 限制

- 資料是依戶籍登記的教育程度註記編製，不是抽樣調查，也不是在學學生數；「碩博士人數」是具該學歷的人口，不是當年的研究生人數
- 戶籍所在地不等於實際居住地
- 96–97 年研究所未分博士、碩士；**98–99 年博士人數偏低，100 年起才穩定**，博士與碩士分開的趨勢只能從 100 年看。檔案沒有說明原因
- 高雄 96–98 年為縣市兩列相加，99 年起為合併後範圍，99 年前後的差異不一定全是真實的人口變化
- 縣市表沒有年齡層與性別，不能拆分
- 圖表只描述高低與差異，不代表因果
